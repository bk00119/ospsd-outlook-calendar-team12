# Calendar Client API

The `calendar_client_api` package defines the abstract interface for all calendar client implementations.

## Module: `client`

::: calendar_client_api.client
    options:
      show_root_heading: true
      heading_level: 3

## Module: `event`

::: calendar_client_api.event
    options:
      show_root_heading: true
      heading_level: 3
